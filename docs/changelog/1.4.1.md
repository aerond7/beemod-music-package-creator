# BMPC 1.4.1 Changelog

Source range: changes after the 1.4.0 release commit `b04a692`.

## Changed

- Editing a package now always works with the audio and icons stored in the package instead of the original files on disk, so you see and edit exactly what is in the package even if the originals were changed or removed. This applies to chamber and funnel music, gel SFX, and song icons. Selecting a file again replaces the packaged one with the file from disk.
- When editing loop points of packaged audio, the loop end can't be moved past the previously saved loop end, because the packaged audio ends there.

## Fixed

- Fixed the loop points editor staying empty, and loop points not being editable, when editing a package whose original audio files no longer exist.
- Fixed saved loop points being lost, and the package update failing, when editing a song whose original audio file no longer exists.
- Fixed the loop points editor still showing the previous loop after selecting a new chamber or funnel audio file.
- Fixed BMPC failing to start or crashing on exit when a file in its temp folder is locked by another program. Locked files are now skipped and cleaned up later.
